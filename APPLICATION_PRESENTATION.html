Overview

Savings Tracker v2.0 is a Flask-based enterprise web application for tracking procurement value across three initiative types:

  • Cost Savings
  • Rebates
  • Cost Avoidance

It modernizes data capture, approval workflows, reporting, and accountability for procurement teams.

What Changed from v1.0

Top Message for Audience

The v2.0 release is not just a refactor. It introduces a formal ORM data model, a better UI, and two core business upgrades: IIS-based login with database authorization, and rebate extraction for reporting/export workflows.

Compared to version 1.0, version 2.0 introduces a stronger technical foundation, cleaner user experience, and two major functional upgrades.

  • Established ORM structure: SQLAlchemy models now define relationships, improve maintainability, and support cleaner data access patterns.
  • Better UI: The interface was modernized with clearer navigation, responsive forms, improved table interactions, and streamlined workflows.
  • Main update 1: Login now uses IIS Windows Authentication, and authorization is enforced through database-backed users, roles, and permissions.
  • Main update 2: Rebate extraction was added to support filtered rebate reporting and export workflows for operational use.

Main Features

  • Role-based access control (Admin, Reviewer, User, Read-Only)
  • IIS Windows Authentication integration for SSO-style sign-in
  • Dashboard with statistics, filtering, and initiative status tracking
  • Separate forms for Cost Savings, Rebates, and Cost Avoidance
  • Facility allocation support with 100% total validation
  • Submit-for-review workflow with reviewer/admin approval actions
  • Initiative approve/reject actions
  • Audit logs for traceability of changes
  • File attachment tracking
  • REST API for CRUD and workflow actions
  • Email notification integration (Microsoft Graph)

Workflow and Controls

  1. User creates or updates initiative data
  2. User creates or updates initiative data and submits for review
  3. Reviewer/Admin evaluates submission
  4. Reviewer/Admin approves or rejects
  5. System records actions in audit trail
  6. Stakeholders receive notification emails

Technology Stack

  • Backend: Flask 3.x, SQLAlchemy ORM, pyodbc
  • Database: Microsoft SQL Server
  • Frontend: Jinja templates, Bootstrap, JavaScript
  • Grid/UI: Responsive HTML table, custom JavaScript sorting/filtering, status indicators
  • Auth: IIS Windows Authentication
  • Notifications: Microsoft Graph API
  • Deployment Target: IIS + FastCGI

Future Opportunities

  • Expanded analytics and KPI trend review
  • Additional export/report automation
