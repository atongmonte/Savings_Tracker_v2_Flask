# Cost Savings Templates

This directory contains Excel templates for different cost savings types.

## Required Templates

1. **standardization_conversion_template.xlsx**
   - For Standardization/Conversion initiatives
   - Should include fields for item comparisons, conversion ratios, etc.

2. **negotiated_price_reduction_template.xlsx**
   - For Negotiated Price Reduction initiatives
   - Should include old vs new pricing comparison

3. **demand_utilization_reduction_template.xlsx**
   - For Demand/Utilization Reduction initiatives
   - Should include usage metrics and reduction targets

4. **one_time_saving_template.xlsx**
   - For One-time Saving (non-rebate) initiatives
   - Should include one-time cost breakdown

## Instructions

Replace this README with actual Excel (.xlsx) template files with the names listed above.
Each template should be customized for its specific savings type.
